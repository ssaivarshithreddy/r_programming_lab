R PROGRAMMING - 21 EXPERIMENTS

This folder contains 21 separate R script files, one for each experiment.

How to use:
1. Extract the ZIP file.
2. Open an individual .R file in RStudio.
3. Run the script.

Dataset notes:
- women, airquality, ChickWeight, iris, USArrests, and Titanic are built-in R datasets.
- Experiment 10 creates exam_data.csv.
- Experiment 11 can create its own sample CSV if exam_data.csv is not present.
- Experiment 17 uses the built-in Titanic table for class/gender plots. Its age histogram is explicitly illustrative because the built-in Titanic dataset has no Age field.
- Experiment 19 creates sample advertising data inside the script; it is not the original external Advertising dataset.

Packages:
- reshape2 is installed automatically when needed in Experiments 12 and 14.
- nnet is installed automatically when needed in Experiment 21.

The scripts may need internet access the first time they install these packages.
